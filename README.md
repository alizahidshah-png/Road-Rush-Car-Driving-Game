# Road Rush — Car Driving Game

A mobile-friendly browser car driving game built with HTML, CSS and JavaScript.

## Features
- 5 stages: Suburban Drive, Desert Highway, Night City, Rainy Mountain, Neon Rush
- Dodge traffic and collect coins
- Keyboard controls (← → or A/D)
- Touch controls for phones
- Pause/resume and stage progression
- No dependencies or build step required

## Play
Open the GitHub Pages link after Pages is enabled, or open `index.html` in any modern browser.

## GitHub Pages setup
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait a minute and open the Pages URL GitHub shows you.

Controls: Left/Right arrow or A/D on desktop; on phones, use the on-screen buttons.
